# react-native-collapsible-fluid-tabs

Smooth collapsible header and tabs for React Native, with synchronized scroll across pages

## Installation


```sh
npm install react-native-collapsible-fluid-tabs
```


## Usage


```js
import { multiply } from 'react-native-collapsible-fluid-tabs';

// ...

const result = multiply(3, 7);
```
