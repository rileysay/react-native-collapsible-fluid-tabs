# Third-party assets

- **beUI animated sidebar**: https://beui.dev/components/motion/animated-sidebar — MIT, Saurabh. Submenu and item motion adapted for the existing documentation navigation. Fumadocs supplies the sidebar shell and routing; Base UI manages disclosures. Hover and selected-page backgrounds stay attached to their rows. See licenses/beui.txt.

- **beUI tabs**: https://beui.dev/components/motion/tabs — MIT, Saurabh. Adapted for keyboard navigation and linked tab panels. See licenses/beui.txt.
- **beUI command palette**: https://beui.dev/components/blocks/command-palette — MIT, Saurabh. Adapted from the supplied source with Base UI focus management, indexed documentation search, Reicon icons, and neutral colors.
- **beUI theme toggle**: https://beui.dev/components/motion/theme-toggle — MIT, Saurabh. The circular View Transition variant, adapted for Reicon icons and reduced motion.
- **iPhone 18 Pro bezels**: Apple Design Resources, distributed in https://github.com/blaineam/Monkr/tree/main/static/devices/iphone-18-pro. Black and silver PNGs are used unchanged to frame the author's iOS-compatible library example. Apple's design-resource terms apply; these assets are not MIT licensed. The screen mask follows the measured cutout. Source URLs, the upstream commit, geometry, and checksums are recorded in public/devices/sources.json. Resources: https://developer.apple.com/design/resources/.
- **Reicon UI icons**: https://github.com/dqev/reicon — MIT. Installed from reicon-react. Upstream also credits Solar Icons by 480 Design (CC BY 4.0) and Zappicon. See licenses/reicon.txt.
- **Brand SVGs**: GitHub, React, Expo, npm, X, and Instagram logo URLs were recovered from Reicon's catalog at commit 62511d9b07f91be25801a8a014323b9e5e331a09, immediately before removal commit 03af559501c401ded6a3a497b7f23917177be1ea. The original SVGs were downloaded from the catalog's CDN URLs and are served locally. See public/brands/sources.json for URLs and hashes. Brand marks identify the linked projects.
- **Interactive demo**: copied from the author's existing Fluid Tabs Expo web export. The library is MIT licensed. The snapshot is served in an iframe; its React Native runtime does not become a dependency of the Next.js app.
- **Shopify logo**: recovered from the same archived Reicon catalog and displayed beside FlashList.
- **Legend logomark**: the official white SVG linked in the header of https://legendapp.com/, displayed beside Legend List. Source URL and checksum are in public/brands/sources.json.
- **Software Mansion symbol**: the official monochrome symbol from https://brand.swmansion.com/, displayed beside Reanimated. Source URL and checksum are in public/brands/sources.json.

Catalog: https://github.com/dqev/reicon/blob/62511d9b07f91be25801a8a014323b9e5e331a09/public/logos-data/icons.json
